# Cloudflare 私人白板

前端静态资源、登录 API 和同步 API 由同一个 Worker 提供；一个 SQLite Durable Object 保存私人文件库、文档版本和登录会话；私有 R2 桶保存附件。无需 Google 登录，也不启用公开注册。

## 使用

打开 [see.yorks0n.com](https://see.yorks0n.com)，展开左侧侧边栏，点击底部「登录」填写账号密码。服务器地址默认是当前站点。登录后底部显示账号，点击账号可立即同步或退出登录。登录后会上传当前浏览器的本地白板，也会下载服务器上的白板。另一台设备打开同一地址并登录即可访问。

标题旁状态点区分本机保存和云端同步：已保存且同步完成时为绿色，内容待保存、正在同步或离线待同步时为黄色，本机保存失败、冲突或云端同步失败时为红色。平移、缩放只保存本机视角，不会使已同步的绿点变黄；无内容变化的后台检查也保持绿色。离线时继续编辑，未发送修改及最后共同版本保存在 IndexedDB，重新连接后自动重试。退出登录撤销当前会话，但保留当前浏览器的白板副本。

GitHub Pages、旧的 `workers.dev` 地址和自定义域名分别使用各自的浏览器存储。旧 Worker 地址已同步的白板可以在新域名重新登录后访问；仅保存在旧站浏览器里的白板可按以下步骤迁移：

1. 在旧站下载需要迁移的 `.canvas` 文件。
2. 在新站导入文件，再登录同步。
3. 在另一台设备确认内容和图片完整后，再处理旧站副本。

如果旧站也发布了本版本，则可以直接在旧站的「云端同步」填写 Cloudflare 地址并登录；`ALLOWED_ORIGIN` 需要是旧站的来源，例如 `https://yorks0n.github.io`，不包含 `/see/`。

## 部署

```sh
npm ci
npx wrangler login
npx wrangler r2 bucket create see-whiteboard-media
npm run cloud:deploy
npm run cloud:password
```

`cloud:password` 在终端隐藏输入密码，生成 PBKDF2-SHA256 哈希后上传 `PASSWORD_HASH` Secret；密码不会进入前端包或 Git。默认账号是 `owner`，可在 `wrangler.jsonc` 中修改。修改密码会使所有旧会话失效，设备需要重新登录。初始化部署在密码设置前拒绝登录。

代码更新后再次运行 `npm run cloud:deploy`；这不会删除已有文档、R2 附件或密码 Secret。`wrangler.jsonc` 里的 Worker 名称、DO 绑定及 R2 桶名应保持稳定。不要删除 Durable Object 命名空间或 R2 桶来升级。

本项目使用 **Workers Static Assets** 托管前端，不是单独的 Pages 项目；它与后端共用一个域名，省去跨域配置。现有 GitHub Pages 可以继续存在。

## 数据与冲突

- 文档：按白板保存版本，服务端使用事务进行版本检查，不接受过期快照覆盖。
- 合并：使用本地、最后共同版本和远端三方比较。不同卡片、不同字段可合并；同一位置的 `x/y` 作为整体；同一文字字段发生并发修改时保存冲突副本，不进行字符级协作。
- 删除：保留墓碑。离线编辑与远端删除相冲突时保留冲突副本。
- 相机：视角留在各设备本机，不会因另一台设备平移而跳动。
- 撤销：远端更新只在当前交互结束、本机保存完成后加载；加载远端版本会清空当前文档的本地撤销栈，避免旧快照撤销覆盖远端内容。撤销栈不上传。
- 历史：服务端最多保留每个白板最近 50 个提交版本；依赖已到期附件的旧版本会随附件一起清理。通过已认证的 `GET /api/boards/:id/history` 和 `GET /api/boards/:id/history/:revision` 获取；目前没有历史恢复界面。这不是独立备份。
- 同步频率：本地提交后短暂合并上传请求；服务端提交新版本后，通过已认证的 WebSocket 通知在线设备，接收端自动下载并应用更新。每 5 秒检查作为兜底，连接恢复、窗口重新获得焦点或页面回到前台时也会检查版本。此阶段同步已提交内容，不传输鼠标位置或逐帧拖拽动画。
- 多窗口：同一浏览器、同一站点的窗口通过 BroadcastChannel 通知已提交的本地变化，接收端从共享 IndexedDB 读取，云端下载的变化也会通知其他窗口。各窗口保留自己的视角；没有内容变化时保留撤销栈。正在交互、输入或尚未保存时暂缓应用，继续使用本地版本保护避免覆盖。
- 推送连接：浏览器通过 WebSocket 子协议携带登录凭据，凭据不放入 URL。服务端使用 Durable Objects 的休眠 WebSocket API；通知在事务提交成功后发出，包含白板 ID 和版本，不携带正文。退出登录会关闭对应会话的连接；推送前也会核对会话有效性。

## 附件

附件按「MIME + 文件内容」的 SHA-256 寻址，文档只保存引用。上传采用 8 MiB 分块，已上传分块会记录在服务器；中断后可重试续传。每块验证 SHA-256，完成时流式校验完整文件，所有附件确认完成后才提交文档。R2 不开放公共域名，下载也必须经过登录鉴权。

单个附件上限 512 MiB，文档 JSON 上限 1 MiB。附件支持 HTTP Range。前端目前仍是图片界面；视频的存储和传输基础已具备，但尚未添加视频播放器。远程 HTTP 图片链接不会自动抓取或归档。

未完成上传约 24 小时后中止。已完成附件失去最后一个当前白板引用后，最多保留七天；仍被其他白板、白板副本或冲突副本使用的附件不会删除。重新引用会取消到期清理，再次删除则重新计算七天。上传完成但尚未被白板引用的附件同样有七天宽限期；同步重试确认复用附件时刷新该宽限期。

云端使用 Durable Object Alarm 按最早到期时间清理，无需设备保持在线。历史版本不延长附件保留期，回收附件时会移除依赖它的历史快照，避免返回无法完整恢复的版本。删除前先持久化清理标记，阻止并发提交新的附件引用；R2 删除失败会保留标记并定时重试。实际执行时间可能受平台调度或服务故障影响。升级前已有的无引用附件从首次检查起保留七天。费用按账户实际 Cloudflare 套餐和用量计费。

## 验证

```sh
npm test
npm run build
npm run cloud:check
npm run cloud:password -- --local
npx wrangler dev
```

运行时集成测试 `scripts/test-cloud.mjs` 只访问 `127.0.0.1:8787`，从传入的密码文件路径读取本地开发密码：

```sh
node scripts/test-cloud.mjs /path/to/local-test-password
```

测试覆盖鉴权、跨域限制、并发版本校验、历史、分块续传、内容校验、范围下载、删除墓碑与注销。测试账号和数据必须使用本地运行时，不应使用线上密码。

断网时已打开的页面可继续编辑；尚未添加 Service Worker，关闭浏览器后在完全离线环境重新打开站点不作保证。
