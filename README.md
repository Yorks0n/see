# see

一个结合空间卡片、自由手绘和分组的白板工具，使用 React、TypeScript 与 Canvas / SVG。数据自动保存在当前浏览器的 IndexedDB，也可导入、导出 `.canvas` 文件。

「文件 → 打开白板」或 `⌘/Ctrl O` 可打开 `.canvas`、tldraw 导出的 `.tldr`，以及包含 tldraw `records` 或 `store` 的 JSON 快照：

- 文字、便签、图片及矩形尽量转换为可编辑节点；嵌套分组会计算全局坐标，多个页面并排放入带名称的分组。图片资源、矩形裁剪、笔迹路径和连接关系会一起导入，兼容新旧箭头绑定及压缩笔迹。
- 带样式的几何形状转换为 SVG 图片，内部文字不能直接编辑；视频和嵌入内容转换为链接。字体、部分富文本、旋转图片、压感、锁定、透明度及复杂箭头效果不能完全还原，不支持的自定义形状保留占位卡片。导入后会显示兼容说明。
- 新导入的文件只保存转换后的白板内容，兼容说明保存在 `meta.tldraw.warnings`；未转换的原始数据不再保存，已有白板中的原始数据不会自动清理。早期 v1 `document.pages` 格式需先用 tldraw 重新导出。
- see 导出的 `.canvas` 可恢复文字、图片及说明/裁剪、附件、链接、矩形、笔迹、节点顺序、分组及背景、列表成员顺序、连线端点/样式/标签/可见性/偏移和视角。本地附件内嵌，外链保留原地址，离线可用性仍取决于资源来源。see 的扩展节点和字段在其他 JSON Canvas 应用中不保证完整显示。

支持部署到 Cloudflare，使用账号密码在多设备间同步；文档保存在 Durable Objects，附件保存在私有 R2。登录入口在「文件 → 云端同步」，部署与数据处理说明见 [Cloudflare 私人白板](docs/cloudflare.md)。

本地保存：

- 白板正文与文件列表以 IndexedDB 为准；清除文件目录偏好不会使已有白板消失。旧版 IndexedDB 和 localStorage 恢复副本会自动迁移，迁移成功前保留源数据。
- 本地图片、临时 Blob 资源按内容哈希保存为独立附件，与文档在同一事务中提交。刷新时恢复图片、裁剪、分组和连线属性。外部 HTTP 图片链接仍是外链，不会自动下载为离线附件。
- 修改后自动保存，持续编辑时也会定期提交。标题旁的状态点表示保存状态；写入失败会显示重试、保存副本和下载入口，未保存时离开页面会提醒。
- 同一浏览器、同一站点的窗口通过 BroadcastChannel 通知已提交的变化，自动更新白板与文件列表，保留各窗口的视角。正在编辑或尚未保存时暂缓更新；数据库事务内的版本检查继续防止并发覆盖，冲突时可保存为副本。页面关闭时会尝试写入恢复记录，旧恢复记录与数据库版本冲突时另存为恢复副本。删除记录保留，防止旧标签页重新写回已删除的白板。
- `.canvas` 下载只包含单个白板及其内嵌本地附件，不包含撤销历史、文件库置顶或当前打开文件。Blob 临时地址在下载时转换为内嵌内容。附件暂不自动清理，避免误删副本、撤销和恢复记录引用的资源。
- “保存到本地”会请求浏览器的持久存储权限，但是否授予由浏览器决定。本地保存属于当前浏览器、当前站点地址；清除站点数据、更换浏览器或域名不会自动迁移。重要白板仍应下载备份。目前未提供离线启动缓存或视频播放界面。

运行与检查：

```sh
npm install
npm run dev
npm test
npm run build
```

基本操作：

- 双击空白处新建文字 block；未输入文字时点击空白处或按 Esc，会移除这张临时卡片。也可以直接粘贴文字。
- 拖动 block 右上方的圆点连接其他 block。拖到空白处会创建关联卡片。连线标签可拖动，始终显示在卡片与笔迹上方；点击连线或标签打开样式面板，修改样式时面板位置保持不动。
- 图片可通过上传、链接、拖入文件或剪贴板添加。单击后显示裁剪、文本注释、复制、图层顺序与删除操作。编辑注释时工具栏保留，清空文字即去掉注释背景；有文字时可通过 Split 拆成图片下方的文本块。
- 图片和文本块共用右下角的小圆弧缩放手柄。图片默认等比缩放，按住 Shift 可自由缩放；文本块默认自由调整大小，Shift 等比缩放。双击图片或点击裁剪，在画布原位置拖动四角、四边与裁剪区域；点击空白、裁剪按钮或按 Enter 退出，Esc 取消当前拖动并退出。裁剪保留原图，可再次进入裁剪并向外拖回。
- 左下角调色板分别设置文本块与连线的默认颜色；文本块默认白色，连线默认 `#609FBB`，只作用于新建内容。
- 多选后点击浮动工具栏的分组图标，或按 `⌘/Ctrl G` 创建分组；也可按 `B` 框出分组。拖动分组标签或空白背景会带动成员；新建、移入分组的内容会加入成员。双击标签重命名，`⌘/Ctrl Shift G` 解组。删除分组边框会保留内容。
- 按 `D` 手绘，支持实时平滑笔迹、颜色与粗细。后绘制的笔迹默认在上层，与卡片和图片按创建顺序叠放。按 `V` 返回选择，可选中笔迹并调整颜色、粗细、大小或置顶、置底。
- Shift 点击增减选择；从空白处拖动，以彗星状渐隐轨迹划过选中文字、图片或笔迹；拖选时按住 Shift 切换为方框框选，松开切回划选，按键先后均可。方框完整包住内容后选中。选中卡片保留颜色蒙层与阴影，选中笔迹显示沿线高亮。方向键微移，Shift + 方向键移动 10 个画布单位。
- 滚轮平移，`⌘/Ctrl + 滚轮` 以光标位置为中心缩放；按住空格拖动或按 `H` 使用抓手。右下角可以缩放、重置比例和适应全部内容。
- `⌘/Ctrl Z` 撤销，`⌘/Ctrl Shift Z` 重做，`⌘/Ctrl D` 创建副本，Delete 删除。拖动中按 Esc 取消当前操作。

顶部与浮动操作栏采用 Phosphor 图标，并提供中文悬浮提示、快捷键提示及无障碍名称。

`npm test` 使用 Vite 编译测试后运行 Node 的测试器，覆盖文档恢复、操作历史、图片元数据、嵌套分组、副本、连接、手绘命中和导入校验。持久化测试使用 fake-indexeddb，覆盖独立附件、事务回滚、多实例冲突、删除记录、恢复迁移和保存失败；不需要启动浏览器。
